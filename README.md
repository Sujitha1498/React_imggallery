# React Image Gallery

A responsive image gallery built using React to demonstrate reusable components, props, array of objects, and the map() method.

## Features

- Reusable Image Card component
- Image details stored in an array of objects
- Dynamic rendering using map()
- Props used to pass image data
- Responsive grid layout
- Clean and modern UI
- React Fragments
- Responsive design for different screen sizes

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite
